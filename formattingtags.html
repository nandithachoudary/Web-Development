HTML Text Formatting Tags

1. Superscript (sup)

Use the <sup> tag to display text as superscript.

Example: ab , we use superscript here.

2. Subscript (sub)

Use the <sub> tag to display text as subscript.

Example: H2O , we use subscript here.

3. Strike-through (strike)

Use the <strike> tag to display text with a strike-through effect.

Example: This text is striked.

4. Super Bold (strong)

Use the <strong> tag for bold text.

Example: This text is super bold.

5. Underline (using CSS)

To underline text, use the text-decoration: underline CSS property.

This text is underlined.
